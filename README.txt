# WeatherBot — Telegram‑бот для прогноза погоды

Бот предоставляет прогноз погоды по городам и умеет автоматически присылать сводку в заданное время. Реализовано через FSM (машина состояний), базу данных Peewee и фоновый планировщик.

## Возможности

- Получение текущего прогноза и прогноза на 7 дней.
- Выбор города из списка.
- Настройка автоматических уведомлений по времени (ежедневно).
- Поддержка состояний (FSM) для пошагового ввода данных (имя, город, время).
- Ведение базы пользователей и их настроек.
- Обработка некорректного ввода (не‑текст, неверный формат времени и т.п.).
- Логирование основных событий.

## Стек технологий

- Python 3.14
- `pyTelegramBotAPI` (telebot) — для взаимодействия с Telegram
- `peewee` — ORM для работы с SQLite
- `schedule` — простой планировщик задач
- `threading` — параллельный запуск polling и планировщика
- `re` — валидация формата времени (ЧЧ:ММ)
- Встроенный `logging` — логирование событий
